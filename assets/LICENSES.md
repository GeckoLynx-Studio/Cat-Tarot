# Asset Licenses

## Tarot card illustrations

- Location: `assets/cards/`
- Files: the 22 supplied Major Arcana PNG files
- Source: supplied by the project owner from the local Tarot asset folder
- License: not specified together with the supplied files

Before redistributing the game publicly, confirm that the card art may be
redistributed. If the license is known, record it here.

The original file names are preserved exactly as supplied. Several names contain
spaces and leading numbers; this is intentional.


## Low-poly dice model

- Source: `assets/models/source/dice_low_poly.blend`, provided by the project
  owner from the local `DiceLowPoly.blend` file
- Runtime: `assets/models/dice_low_poly.glb`, exported from that blend with
  Blender 4.2.9
- License: not specified together with the supplied file

The source folder contains a `.gdignore` file so Godot imports only the GLB.
Confirm redistribution rights before publishing the game.

## Icons

- Location: `assets/icons/`
- Source: the supplied `no-padding` icon pack in the local game asset folder
- License: not specified together with the supplied files

The icons are used for resource/stat indicators and action affordances. The
`*_color.png` stat icons are derived from the supplied white icons using the
project's stat colors. Confirm redistribution rights before publishing the game.

## Card, deck, and dice sound effects

- Location: `assets/audio/sfx/`
- Source: the supplied tabletop sound pack (`tables` folder) in the local game
  asset library
- Files used: `card_draw`, `card_flip`, `card_slide`, `card_tap`,
  `card_discard`, `card_reveal`, `card_fan_open`, `dice_roll`
- License: not specified together with the supplied files

The supplied WAVs are 24-bit PCM; they were converted to 16-bit PCM at 48 kHz so
Godot can import them. Confirm redistribution rights before publishing the game.
